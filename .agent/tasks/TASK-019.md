### AC-3: Root README.md — Setup instructions
Step-by-step instructions covering:

1. Clone the repository
2. Build Docker test runner image:
   ```bash
   docker build -t migration-verifier-runner docker/test-runner
   ```
3. Install backend dependencies:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```
4. Start backend server:
   ```bash
   cd backend
   uvicorn main:app --reload --port 8000
   ```
5. Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```
6. Start frontend dev server:
   ```bash
   cd frontend
   npm run dev
   ```
7. (Optional) Set Gemini API key:
   ```bash
   export GEMINI_API_KEY=your_key_here
   ```

### AC-4: Root README.md — Demo walkthrough
Step-by-step demo instructions:

1. Ensure backend and frontend are running
2. Create demo zip files:
   ```bash
   cd demo
   zip -r original.zip original/
   zip -r migrated.zip migrated/
   ```
   Or on Windows:
   ```powershell
   Compress-Archive -Path demo\original\* -DestinationPath demo\original.zip
   Compress-Archive -Path demo\migrated\* -DestinationPath demo\migrated.zip
   ```
3. Open browser to `http://localhost:5173`
4. Upload `original.zip` and `migrated.zip`
5. Wait for analysis to complete
6. Expected result: "REGRESSION DETECTED"
7. Walk through each tab: Summary, Changes, Impact, Tests, Evidence
